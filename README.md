## Replication Goals

- Confirm we can capture similar markings in Instax films
- Confirm Which direction more events occur (Tip, Base or Sides)
- Confirm Orientation of the cone
- Confirm RPM to event counts
- Confirm if Solid body has same effects vs Cone
